================================================================================
DECISIONES TÉCNICAS TOMADAS
================================================================================

1. TECNOLOGÍAS:
   - Electron 28.x + React 18.x + Vite 5.x
   - SQLite (local) + PostgreSQL (servidor)
   - better-sqlite3 (síncrono, más rápido)
   - jsPDF para PDFs
   - xlsx para Excel
   - Express para servidor
   - Railway para hosting

2. ARQUITECTURA:
   - Cliente-servidor con DB local
   - Idempotency keys para prevenir duplicados
   - Batch processing cada hora para envío SII
   - Sistema de licencias con machine ID

3. PRIORIDADES:
   - Funcionalidad > Perfección
   - Cliente completo antes que servidor
   - Testing manual continuo
   - Commits frecuentes

4. SEGURIDAD:
   - contextIsolation: true
   - nodeIntegration: false
   - Preload script como bridge único
   - Prepared statements (SQL injection)
   - Variables entorno para secretos
